Stripe Connect web_test_webview — isStripeDomain() Suffix Bypass PoC

This PoC demonstrates that connect-js.stripe.com/v1.0/web_test_webview.html validates the parent origin using hostname.endsWith('connecttest.onrender.com') without a leading dot, allowing any attacker-controlled Render subdomain ending in "connecttest" (e.g. xconnecttest.onrender.com) to pass the check and send arbitrary messages to the webview, including callSetterWithSerializableValue.

Vulnerability Summary

[BUG] isStripeDomain.ts uses:
hostname.endsWith('connecttest.onrender.com')
instead of:
hostname.endsWith('.connecttest.onrender.com') || hostname === 'connecttest.onrender.com'

Affected entries (9 unsafe, all missing leading dot): 
connecttest.onrender.com
stripe-connect-test.onrender.com
stripe-connect-furever.onrender.com
hamster-dance.onrender.com
issuing-embedded-components-app.vercel.app
property-management-tau.vercel.app
embedded-finance-app.vercel.app
gym-management-mvhg.vercel.app
coffee-shop-management-liard.vercel.app
Safe entries (have leading dot): .stripe.com, .stripe.me, .furever.dev
